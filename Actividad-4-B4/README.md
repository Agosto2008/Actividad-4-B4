# Actividad-4-B4# Mini App de Lista de Usuarios

Aplicación web interactiva que consume la API de JSONPlaceholder para mostrar una lista de usuarios con filtro de búsqueda en tiempo real.

## Tecnologías e Herramientas
- HTML5, CSS3, JavaScript (ES6+)
- **pnpm** (Gestor de paquetes)
- **ESLint** (Linter para validación de código)
- **Husky** (Hooks para automatización de Git)

## Configuración e Instalación
1. Clonar el repositorio.
2. Instalar dependencias con `pnpm install`.
3. Al realizar un `git commit`, Husky ejecutará automáticamente `pnpm exec eslint .` para validar que el código no contenga errores de estilo o sintaxis.
